POTATO EQ - installing

Easiest: run the installer (PotatoEQ-x.y.z-Windows-Setup.exe or PotatoEQ-x.y.z-macOS.pkg).
  Windows: if SmartScreen says "Windows protected your PC", click "More info" > "Run anyway"
           (the installer isn't code-signed yet).
  macOS:   if it says the package can't be opened, go to System Settings > Privacy & Security
           and click "Open Anyway" (the installer isn't signed by Apple yet).

Manual install (copying the files yourself):

Windows (FL Studio, Ableton, Reaper, Studio One, Cubase, Bitwig ...)
  1. Copy the "Potato EQ.vst3" folder to:  C:\Program Files\Common Files\VST3
  2. In FL Studio: Options > Manage plugins > Find more plugins (or Find installed plugins).
     Potato EQ appears under Effects. Other DAWs rescan VST3 on start-up.
  "Potato EQ.exe" is a standalone version for quick testing without a DAW.

macOS (Logic uses the .component / AU, everything else the .vst3)
  1. Copy "Potato EQ.vst3"      to  ~/Library/Audio/Plug-Ins/VST3
     Copy "Potato EQ.component" to  ~/Library/Audio/Plug-Ins/Components
  2. The plugin isn't signed by Apple yet, so macOS will block it the first time.
     Open Terminal and run:
       xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/VST3/"Potato EQ.vst3"
       xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/Components/"Potato EQ.component"
  3. Restart your DAW.
